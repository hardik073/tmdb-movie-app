Movie App
=========

A movie discovery Android application built from scratch.

The goal of this project is not just to build another movie app,
but to document the complete engineering journey:

Product → Requirements → Design → Architecture → Development → Testing → Release

## Project Status

Phase 2 — UI/UX Design 🚧
Phase 3 — Android Implementation ⏳

## Project Goal

Build a production-minded Android movie application while documenting
the decisions, trade-offs, and lessons learned throughout the process.

The architecture is intentionally kept proportional to the complexity
of the product. The goal is to build something understandable,
testable, and maintainable rather than over-engineering the project.
